# Telegram-Survivor

Мобильный top-down survival shooter на HTML5 Canvas для Telegram Mini Apps.

## Первый прототип
- Управление касанием: удерживай и перемещай палец, чтобы двигаться.
- Автоматическая стрельба по ближайшему противнику.
- Враги появляются волнами и постепенно ускоряются.
- Здоровье, таймер, счёт убийств и опыт.
- При повышении уровня можно выбрать одно из трёх улучшений.
- Частицы, свечение, сетка арены и лёгкая тряска при получении урона.
- Подключён Telegram Web Apps SDK; игра также запускается в обычном мобильном браузере.

## Запуск
Открой `index.html` через локальный веб-сервер или опубликуй репозиторий через GitHub Pages.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Это ранний игровой прототип. Следующие этапы: баланс волн, разнообразные враги, оружие, боссы, постоянные мета-улучшения и сохранение прогресса.
